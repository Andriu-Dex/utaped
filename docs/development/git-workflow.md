# Flujo Git

main contiene versiones terminadas. develop integra entregas mediante PR. Implementaciones en feature/*, correcciones en fix/* y documentación en docs/*. PR hacia develop, con validación y reporte; versiones completas por PR develop → main.

Esta entrega se prepara en feature/project-foundation. No hacer commits, push ni PR automáticamente sin autorización para esas acciones. CI localmente definido verifica frontend y backend; su ejecución remota comienza al publicar y depende de GitHub Actions del repositorio.
