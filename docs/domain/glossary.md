# Glosario

| Término | Identificador propuesto | Significado |
|---|---|---|
| Usuario autenticado | authenticatedUser | Identidad real de sesión. |
| Contexto activo | activeContext | Rol/grupo elegido; no cambia identidad. |
| Grupo institucional | institutionalGroup | Comisión, unidad, club u otro configurable. |
| Pertenencia | membership | Usuario/grupo con rol y vigencia. |
| Plan T1 | workPlan | UTA-SGC-A-2-1-P7-T1. |
| Informe T2 | report | UTA-SGC-A-2-1-P7-T2; normalmente derivado del Plan. |
| Artefacto | documentArtifact | Composición persistida e identificada del documento. |
| Plantilla congelada | templateSnapshot | Versión/configuración aplicada al documento. |
| Versión formal | formalVersion | Versión institucional, diferente de ronda. |
| Ronda | reviewRound | Ciclo de revisión del artefacto. |
| Etapa | workflowStage | Participantes y condiciones del flujo. |
| Ubicación de firma | signatureSlot | Metadata de la composición real. |
| Anexo | attachment | Parte/adjunto documental distinto de evidencia. |
| Medio | verificationMethod | Medio elegido al planificar. |
| Evidencia | evidence | PDF de ejecución ligado al medio. |
| Versión de evidencia | evidenceVersion | Reemplazo histórico del PDF. |
| QIPOC | QIPOC | Procedimiento/documento externo no confirmado. |

Vocabulario propuesto; no define SQL ni contrato API definitivo.
